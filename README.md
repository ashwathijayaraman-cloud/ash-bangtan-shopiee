#  Bangtan Shopiee

A modern and responsive stationery store website designed with a clean, cute, and user-friendly interface.

##  Live Demo

🔗 https://ash-bangtan-shopiee.lovable.app

## About the Project

Bangtan Shopiee is a web-based stationery store project created to provide a simple, engaging, and visually appealing online shopping experience.

The project focuses on modern UI/UX design, responsive layouts, product browsing, and an easy-to-use shopping interface.

## Key Features

- Modern and responsive home page
- Product search and browsing
- Product categories and product cards
- Like / favourite products
- Add to Cart functionality
- Order Now interface
- Detailed product information
- Login and Sign Up interface
- Forgot Password option
- User profile section
- Cute stationery-themed UI
- Smooth transitions and micro-animations
- Responsive design for mobile and desktop

## Technologies Used

- React
- TypeScript
- Vite
- Tailwind CSS
- Lovable
- GitHub

##  UI/UX Highlights

- Clean and modern visual design
- Responsive layout for different screen sizes
- Rounded cards and components

- Simple and engaging shopping experience
