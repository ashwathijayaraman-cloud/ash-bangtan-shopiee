# Bangtan Stationery Studio

Professional UI/UX Design Prompt



Design a modern, cute, and user-friendly Stationery Shop Website UI/UX named "Bangtan Shopiee".



Brand Identity



Website name: Bangtan Shopiee



Mascot: A small, adorable panda holding a pencil.



The panda should appear beside the shop name in the header and on the login page.



Design style: Minimalist, elegant, playful, and student-friendly.





Color Palette



Primary background color: Champagne



Borders, outlines, and accent elements: Coffee Brown



Soft shadows and clean typography.



Warm and aesthetically pleasing stationery-themed design.





Landing Page Animation



When the website opens, display a smooth animation:



A cute panda runs onto the screen.



The panda jumps playfully.



After the animation, the Bangtan Shopiee logo, login form, and website content fade in smoothly.







Navigation Sidebar (Left Side)



Circular profile picture at the top-left corner.



User name displayed below the profile picture.



Clicking the profile section opens a dropdown or sidebar menu containing:



Dashboard



Settings



Cart



Liked Items



Logout







Header Section



Shop name "Bangtan Shopiee" displayed prominently in bold.



Cute panda mascot holding a pencil positioned beside the shop name.



Below the logo section, display a row of stationery category names such as:



Pencil Boxes



Color Pens



Stickers



Notebooks



Highlighters



Art Supplies





Categories should be visually appealing and easy to browse.





Search Section



Large centered search bar.



Modern rounded corners.



Coffee-colored outline.



Placeholder text: "Search stationery items..."





Product Showcase



Horizontal Scroll Section



Directly below the search bar.



Display multiple stationery products in a horizontal carousel.



Smooth scrolling interaction.





Vertical Product Grid



Below the horizontal carousel.



Display multiple stationery items in a clean card layout.



Product cards should include:



Product image



Product name



Price



Like icon







Product Detail Page



When a user clicks a product:



Product image displayed prominently.



Product name at the top.



Like button (heart icon).



Add to Cart button.



Order Now button.



Product Details section with description, specifications, and pricing information.



Clean and elegant layout.





Login Page



Everything centered on the screen.



Cute panda mascot displayed above the form.



Shop name Bangtan Shopiee displayed prominently.



Username field.



Password field.



Forgot Password option.



Sign Up option.



Rounded input fields with coffee-colored outlines.



Champagne-colored background with a premium aesthetic.





Overall Design Requirements



Fully responsive design for desktop and mobile.



Modern UI/UX with smooth transitions and micro-animations.



Cute stationery-themed illustrations.



Soft shadows, rounded corners, and premium visual hierarchy.



Clean, elegant, and visually engaging shopping experience.
