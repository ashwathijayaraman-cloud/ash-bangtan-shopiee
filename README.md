# Bangtan Shopiee

A modern and responsive stationery store website designed with a clean, cute, and student-friendly UI/UX.

## Live Demo

[View Live Website](https://ash-bangtan-shopiee.lovable.app)

## About the Project

Bangtan Shopiee is a web-based stationery store created as my first independent web development project.

The project focuses on providing a simple and engaging shopping experience with user-friendly navigation, interactive features, smooth animations, and a responsive design.

## Features

- Responsive home page
- Product search and browsing
- Stationery product categories
- Product details
- Like and favourite products
- Shopping cart
- Order Now interface
- Login and Sign Up interface
- User profile section
- Smooth animations and interactions
- Mobile and desktop responsive design

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS
- Supabase
- Lovable
- GitHub

## UI/UX

The website was designed with a focus on:

- Clean and modern layouts
- Simple navigation
- User-friendly interface
- Responsive design
- Consistent visual styling
- Smooth transitions and animations
- Easy shopping experience

## Project Objective

The main objective of this project is to create a user-friendly online stationery shopping experience while exploring web development, UI/UX design, and AI-assisted development.

## AI-Assisted Development

This project was developed using AI-assisted development tools. I worked on defining the requirements, refining prompts, testing features, identifying issues, and improving the project through multiple iterations.

As my first independent project, this experience helped me understand prompt engineering, debugging, problem-solving, user flows, and the importance of continuous testing.

## Getting Started

### Prerequisites

- Node.js
- npm

### Installation

Clone the repository:

```bash
git clone https://github.com/ashwathijayaraman-cloud/ash-bangtan-shopiee.git
```

Navigate to the project directory:

```bash
cd ash-bangtan-shopiee
```

Install the dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
